# Britton Platt Portfolio

Static HTML/CSS/JS site. No build step.

## Run locally
    python3 -m http.server 8000     # then open http://localhost:8000
Or open `index.html` directly in a browser.

## Structure
- `index.html`, `art.html`, `speeches.html`, `resume.html` : pages
- `css/` : `style.css` (home), `art.css`, `speeches.css` (résumé page keeps its styles inline)
- `js/` : `main.js` (home), `art.js`, `speeches.js`
- `images/` : all photos and logos
- `Britton_Platt_Resume.pdf`, `Rough_Seas_Better_Navigation.pdf` : downloads

## Deploy
Upload the whole folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, Vercel).
